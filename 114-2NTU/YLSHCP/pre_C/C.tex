\section*{C. 困難題}
\end{center}

\section*{Description}

這是一個難度較高的題目，給定一個數列$a_1, a_2, \ldots, a_n$以及一個整數$k$，請輸出任意一組區間$l, r$，使得$\displaystyle\sum_{i=l}^r a_i$的值恰好為$k$（i.e. $a_l + a_{l+1} + \ldots + a_r = k$）。如果有多組區間符合條件，請輸出任意一組即可。若不存在任何區間符合條件，請輸出$-1$。

\section*{Input}
第一行為兩個正整數$n, k$，代表數列的長度以及目標和。

第二行為$n$個整數$a_1, a_2, \ldots, a_n$，代表數列的元素。

其中$1\le n, k\leq 2\times 10^5$，$-10^9 \le a_i \le 10^9$。

\section*{Output}

對於每一組測資，輸出兩個整數$l, r$，代表區間的起點與終點（$1\le l \le r \le n$）。若不存在任何區間符合條件，請輸出$-1$。
