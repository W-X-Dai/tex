\section*{一、申請動機}
從高中開始，我便對資訊科學抱有濃厚的興趣，自學 Linux、LaTeX，並打下 C++ 與演算法的基礎。我認為資訊科學需要一個應用領域來發揮，因此選擇就讀臺大醫工系，希望將自己的能力應用於醫療。我始終相信，若不能在白紙上寫下數學推導、從空白檔案實作程式碼，就不算真正理解一項技術。為此，我曾以 C++ 從零實作包含反向傳播與 SGD 的類神經網路模組，也曾花費數天推導注意力機制並以 Python 實作。

升大三的暑假，我首次進入實驗室，參與以 Multi-Task Masked Autoencoder（MTMAE）從胸部 CT 預測 PD-L1 表現的研究，主要負責重現並延伸學姐的碩士論文。從暑假開始時連 TensorFlow 與 PyTorch 都分不清楚，到結束時已能運用交叉驗證與多種指標評估模型表現。這段經驗讓我理解，研究不只是訓練模型，更需要文獻搜尋、實驗設計與嚴謹的結果評估。後來，實驗室將學姐的原始研究投稿至 Scientific Reports，我在 Rebuttal 階段協助重現實驗結果，補充 ROC、AUPRC 曲線與 Wilcoxon 檢定。論文最終成功發表，我也列為第四作者，並從中體會到研究結果的可重現性與統計驗證的重要。

大三上學期，我轉向 3D 肺結節紋理生成研究，嘗試在擴散模型中以不同方式結合 MSE 與 DoG 損失函數，結果卻始終不理想。與指導教授討論後，我才意識到，自己一直把研究當成樂高積木，不斷拼湊看似有用的方法，卻很少思考自己究竟想解決什麼問題。真正重要的或許不是如何調整損失函數，而是先理解醫學影像中的紋理究竟具有什麼特性，以及模型應該保留什麼。

大三下學期，我選修呂東武老師開設的「機器學習在人體動作分析之應用」，接觸到 Physics-driven 的建模思維，也因此重新檢視自己的紋理研究。我開始透過實驗探究影像紋理的空間特性，嘗試區分真實組織結構與影像形成、重建過程所造成的影響，再據此思考模型應受到哪些約束。過去我要求自己理解演算法「為什麼有效」，現在則更進一步思考它「為什麼應該對眼前的問題有效」。 這讓我逐漸體會到醫學工程跨領域訓練的價值：唯有理解醫學影像背後的資料特性，才能提出有意義的模型假設，而不只是套用現成架構。同一學期，我也在李濬屹老師的深度強化學習課程中，與組員完成一篇探討強化學習應用於編譯器優化的論文，並經歷 OpenReview 投稿、Rebuttal、同儕審查與 Poster Session，第一次完整的參與一篇論文的生命週期。

如今升上大四，我持續修習多模態人工智慧，並於衛福部次世代智慧醫療平台辦公室實習，接觸 AI 在醫療場域的實際應用。回顧這幾年的探索、挫折與反思，我認為自己已經做好準備，從「學習如何做研究」邁向「獨立探索一個研究問題」。然而，我也深知，相較於國際頂尖研究者，自己在理論深度、研究視野與經驗累積上仍有相當大的成長空間。比起不斷追逐新的模型架構，我更希望建立一套從問題觀察、物理直覺、數學建模到實驗驗證的完整研究方法，尤其是將對資料的直覺轉化為明確且可驗證的數學假設。我期望透過醫工所的跨領域訓練、研究資源與師長指導，進一步深化這些能力，逐步成為能夠獨立提出問題、設計方法並驗證結果的研究者，朝國際水準邁進。
